# 🖼️ Image to Emoji Converter

A fast and simple JavaScript-based converter that transforms any uploaded image into copyable pixel art blocks made out of emojis. Perfect for sharing in text chats, Discord, WhatsApp, or social media platforms.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the `index.html` file directly in any modern web browser.

## 🛠️ Built With
* HTML5 / CSS3
* Vanilla JavaScript
* [p5.js](https://p5js.org) (Used for pixel color sampling)

## 🌐 Deploying to GitHub Pages
1. Go to your repository settings on GitHub.
2. Navigate to **Pages** on the left sidebar.
3. Under **Build and deployment**, set the source to **Deploy from a branch**.
4. Select the `main` (or `master`) branch and click **Save**.
5. Your live site will be ready in a couple of minutes!
